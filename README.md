# CampusBites 🍔⚡

> **One Group. One Cart. Everyone Orders.**  
> A lightweight, responsive web application designed for university students to order food together and split bills seamlessly without passing a single phone around.

---

## 🌟 Key Features

* **Squad Group Ordering:** Multiple users can add items simultaneously to a single shared squad cart (`CB-7X2W`).
* **Automated Bill Splitter:** Calculates proportional payment shares, individual subtotals, and taxes per group member.
* **Light / Dark / Auto Theme Switcher:** Automatically syncs with system appearance preferences or toggles manually with a single click.
* **Responsive Campus Portal:** Mobile-first layout designed for browsing campus outlets, menu items, and tracking order progress.
* **Zero External Dependencies:** Built with pure vanilla Web technologies (HTML5, CSS3, JavaScript ES6) for maximum speed and simplicity.

---

## 🛠️ Built With

* **HTML5** – Semantic layout structures
* **CSS3** – Custom properties (variables), Flexbox, CSS Grid, and adaptive theme switching
* **JavaScript (ES6+)** – Client-side dynamic DOM manipulation and state management
* **Google Fonts & FontAwesome** – Inter, Outfit typography, and UI icons
